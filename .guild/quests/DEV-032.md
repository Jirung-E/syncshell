PowerShell 7(PSReadLine 예측)처럼, 입력 중인 내용과 앞부분이 같은 예전 명령을 커서 뒤에 흐린 글씨로 보여주고 → 키(또는 End)로 받아들이는 히스토리 기반 자동완성.

## 방향 (초안)
- 줄 편집은 셸이 하므로 셸 쪽 기능을 켜는 방식을 우선 검토한다. 앱이 직접 흐린 글씨를 덧그리면 셸의 줄 편집 상태(커서 이동, 탭 완성, 여러 줄)와 어긋나기 쉽다.
  - zsh: BUG-003의 ZDOTDIR 셸 통합 파일에서 자동완성(zsh-autosuggestions 방식, POSTDISPLAY 사용)을 켠다. 사용자가 이미 같은 플러그인을 쓰면 중복 로드하지 않는다.
  - PowerShell: PSReadLine 2.1+면 `Set-PSReadLineOption -PredictionSource History`. Windows PowerShell 5.1 기본 PSReadLine(2.0)은 예측이 없음 → pwsh 7이 있으면 기본 셸로 쓰는 것, 또는 PSReadLine 업데이트 안내 검토.
- 켜고 끄기: `config.toml` 설정 항목.
- 흐린 글씨 색이 테마(다크/라이트)에서 잘 보이는지 확인.
