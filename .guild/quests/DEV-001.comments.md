## macOS에서 확인

- `cargo build --release -p syncshell` 성공, `./target/debug/syncshell` /
  `./target/release/syncshell` 둘 다 크래시 없이 뜨고 정상 종료됨(DEV-018에서
  이미 여러 번 확인).
- **콜드 스타트 시간(release, Apple Silicon)**: 프로세스 실행부터 CPU가 idle로
  안정화되기까지 ~1.8초(초기 GPU/윈도우 셋업 버스트 후 안정화). 기준선으로 기록.
- `ViewportBuilder::resizable(true)` 확인 — 창 크기 조절 자체는 막혀있지 않음.
  터미널 리사이즈 크래시(architecture 규칙 7 — 극단적으로 좁은 컬럼 수에서
  alacritty_terminal이 수 GB 할당 시도)는 `TerminalSession::resize`의
  `MIN_COLS`/`MIN_ROWS` clamp로 이미 자동 테스트에서 검증돼 있음.
