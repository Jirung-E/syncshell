앱을 다시 켤 때 탭과 탭별 경로를 복원하지 않는다. 사용자 결정: 시작은 항상 홈 폴더 탭 하나.

## 범위
- `state.toml`에 탭 목록(`tabs`)·활성 탭(`active_tab`)을 더 이상 저장·복원하지 않음
- 시작 폴더: 홈(`HOME` / `USERPROFILE`) → 없으면 실행 위치 → 그마저 없으면 루트
- 창 위치·크기, 테마, 보기 방식, 분할 방향, UI 배율, 글자 크기 복원은 유지
- 예전 `state.toml`(tabs 포함)도 오류 없이 읽힘 — 모르는 항목은 무시, 다음 종료 때 사라짐
- 새 탭은 지금처럼 보고 있던 탭 폴더에서 시작 (변경 없음)

BUG-002(macOS 세션 복원이 저장 경로를 덮어씀)는 이 결정으로 취소.

## Test plan
- 아무 폴더로 이동한 뒤 앱을 끄고 다시 켜기 → 홈 폴더 탭 하나로 시작
- 터미널에서 다른 폴더(예: 프로젝트 폴더)에서 실행해도 홈에서 시작
- 탭 여러 개 연 채로 끄고 켜기 → 탭 하나만 열림
- 창 크기·위치, 테마, 보기 방식, 분할 방향, UI 배율·글자 크기는 그대로 복원
- 예전 `state.toml`(`[[tabs]]` 포함)이 있어도 오류 없이 켜지고, `.bak`가 생기지 않으며, 끄고 나면 `tabs` 항목이 사라짐
- (Mac 확인됨: 예전 state의 /tmp 무시, 프로젝트 폴더에서 실행해도 홈으로 열림, 창 크기 1100×700 유지)
