다중 탭과 분할 터미널을 지원한다.

## 범위
- 탭: 각 탭이 독립된 (탐색기 경로 + 터미널 세션) 쌍을 가짐
- 탭 추가/닫기/전환, 키보드 단축키
- 터미널 분할(수평/수직), 분할된 각 패널이 자체 PTY 보유
- 활성 패널과 탐색기가 동기화 — 패널 포커스 전환 시 탐색기도 해당 패널 cwd로 이동
- 패널 크기 조절 시 각 PTY 리사이즈 전달

## 결정할 것
- 분할 패널이 여러 개일 때 탐색기는 활성 패널만 따라갈지, 탐색기도 분할할지

## Test plan
- 탭 여러 개에서 각각 다른 경로 유지
- 분할 패널 간 포커스 이동 시 탐색기가 정확히 따라감
- 탭/패널 닫을 때 PTY와 워처가 누수 없이 정리되는지
