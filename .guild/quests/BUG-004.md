Windows에서 `cargo test --workspace`(기본 병렬)를 돌리면 `terminal_widget::tests::pos_to_cell_accounts_for_scrollback_offset`가 매번 실패한다(단독·`--test-threads=1`에선 통과). 2026-10-03 Windows 세션이 d929004에서 확인.

## 원인
PowerShell에 80줄 출력 명령을 보낸 뒤 고정 80프레임만 돌림 → 병렬 실행으로 PowerShell 세션이 여럿 뜨면 출력이 덜 와서 스크롤백이 1줄만 쌓이고, `scroll_display(Delta(10))`이 1로 잘려 기대값(-8) 대신 1이 나옴. UI 테스트 수가 늘면서(20→52) 드러남. 코드 회귀 아님.

## 수정
- 마지막 줄(`line80`)이 보일 때까지 `wait_for_row`로 기다림
- `wait_for_row` 최대 대기 2초 → 5초(조건 충족 시 즉시 반환이라 평소 시간은 같음)

## Test plan
- Windows에서 `cargo test --workspace`(기본 병렬)를 3회 돌려 모두 통과하는지 (macOS에선 이 테스트가 컴파일만 됨 — `cargo check --target x86_64-pc-windows-msvc --tests` 통과 확인)
