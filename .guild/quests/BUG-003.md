macOS zsh에서 터미널 시작 시 OSC 7 훅 주입 명령(`_syncshell_osc7() { ... }; add-zsh-hook precmd _syncshell_osc7`)이 화면에 그대로 두 번 찍힌다.

## 재현
앱 실행 → 터미널 첫 화면에 긴 함수 정의 한 줄이 에코되고 프롬프트 뒤에도 한 번 더 보인다.

## 기대
Windows(PowerShell) 쪽처럼 주입 내용이 사용자에게 안 보이거나 최소한 한 번 화면을 지운 뒤 깨끗한 프롬프트로 시작.

DEV-023 작업 중 실행 화면으로 발견(develop 빌드에서도 동일).
