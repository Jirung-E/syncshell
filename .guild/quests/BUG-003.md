macOS zsh에서 터미널 시작 시 OSC 7 훅 주입 명령(`_syncshell_osc7() { ... }; add-zsh-hook precmd _syncshell_osc7`)이 화면에 그대로 두 번 찍힌다.

## 재현
앱 실행 → 터미널 첫 화면에 긴 함수 정의 한 줄이 에코되고 프롬프트 뒤에도 한 번 더 보인다.

## 기대
Windows(PowerShell) 쪽처럼 주입 내용이 사용자에게 안 보이거나 최소한 한 번 화면을 지운 뒤 깨끗한 프롬프트로 시작.

DEV-023 작업 중 실행 화면으로 발견(develop 빌드에서도 동일).

## 해결
- zsh는 훅을 타이핑해 넣지 않는다. `ZDOTDIR`을 `~/.syncshell/shell/zsh/`로 바꿔 띄우고, 그 폴더의 `.zshenv`·`.zprofile`·`.zshrc`가 사용자 원래 시작 파일을 읽은 뒤 OSC 7 훅을 등록한다(VS Code 셸 통합과 같은 방식). 사용자 파일은 건드리지 않음.
- 끝나면 `ZDOTDIR`은 사용자 값으로 돌아가고(원래 없었으면 unset), `/etc/zshrc`가 잡은 히스토리 파일 위치도 사용자 쪽으로 돌린다.
- macOS 터미널 앱에서 물려받은 `TERM_PROGRAM`/`TERM_SESSION_ID` 때문에 돌던 그 앱 전용 세션 복원(`Restored session: …`)을 끈다: `TERM_PROGRAM=syncshell`, `TERM_SESSION_ID` 제거.
- 통합 파일을 쓸 수 없으면 예전처럼 타이핑 주입으로 폴백. PowerShell은 변경 없음.

## Test plan
- macOS에서 앱 실행 → 터미널 첫 화면에 `_syncshell_osc7…` 줄과 `Restored session:`이 없고 깨끗한 프롬프트만 보임
- 평소 쓰는 프롬프트·별칭·PATH 등 `~/.zshrc` 설정이 그대로 적용됨
- `cd`로 폴더를 옮기면 탐색기가 따라감 / 탐색기에서 폴더를 옮기면 터미널이 따라감
- 명령 히스토리(↑)가 평소 히스토리 그대로이고, 새로 친 명령이 `~/.zsh_history`에 남음
- 터미널 안에서 `zsh`를 다시 띄워도 정상(사용자 설정 그대로)
- (Mac 확인됨: 깨끗한 첫 화면, 사용자 프롬프트 적용, 동기화됨)
