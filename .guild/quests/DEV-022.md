탐색기의 "좌측 폴더 트리 + 우측 목록" 2단 구조를 시안의 **트리 보기** 하나로 합친다. 아이콘 보기는 유지한다(트리/아이콘 전환).

시안: https://claude.ai/artifact/C5DJqUWwdJNrKDGxBCZsDz (통합안 아트보드, 탐색기 경로바 오른쪽 전환 버튼)

## 범위
- 트리 보기: 현재 폴더의 항목을 열(이름·크기·수정일)과 함께 보여주고, 폴더 옆 화살표로 그 자리에서 펼침/접기(하위 폴더+파일)
  - 폴더 이름 클릭 = 그 폴더로 이동(동기화 cd — 기존 단일 클릭 진입 규칙, DEV-015 유지)
  - 파일 단일 클릭 = 선택, 더블클릭 = 열기(기존 유지)
  - 펼친 하위 목록 읽기는 배경 스레드(UI 스레드에서 디스크 읽기 금지 — 기존 트리와 같은 방침)
  - 가상 스크롤 유지(대용량 폴더)
- 좌측 별도 폴더 트리 제거(상위 이동은 경로바/브레드크럼으로)
- 보기 방식(트리/아이콘)은 앱 전역, `state.toml`에 저장·복원
- 전환 UI: 경로바 오른쪽 세그먼트 버튼(트리/아이콘)

## 구현 메모
- 트리 줄은 painter로 직접 그림(화살표·폴더/파일 아이콘·이름 말줄임·크기·수정일), 펼친 항목까지 평탄화해 `show_rows` 가상 스크롤 유지
- 하위 목록은 core `read_dir_sorted`로 배경 스레드에서 읽음. 펼침은 현재 폴더 기준 — 이동하면 초기화, 접으면 캐시 버림
- 알려진 한계: 펼친 하위 폴더 안의 변경은 파일 감시 대상이 아니라 접었다 펼쳐야 반영
- 아이콘 보기의 이모지도 그린 아이콘으로 교체(DEV-023 범위 일부 선반영)
- `state.toml` `[ui] view = "tree"|"icons"`

## Test plan
- 자동: 화살표 클릭 = 펼침(이동 안 함)·하위 파일 표시·하위 폴더 클릭 이동·다시 누르면 접힘, 폴더 이동 시 펼침 초기화, 긴 이름 말줄임, 5000행 프레임 예산, 보기 방식 저장
- 사람 확인: 트리/아이콘 전환 버튼, 라이트/다크 양쪽에서 줄 선택·호버 색, 깊게 펼쳤을 때 들여쓰기, 우클릭 메뉴, 재실행 시 보기 방식 유지
