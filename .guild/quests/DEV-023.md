UI 시안(통합안) 중 테마·탐색기 외 나머지 크롬을 정돈한다.

시안: https://claude.ai/artifact/C5DJqUWwdJNrKDGxBCZsDz (통합안 아트보드)

## 범위
- 탭 바: 카드형 활성 탭 + 동기화 점, 새 탭/닫기 버튼을 그린 아이콘으로
- 분할 모양(좌우/상하) 전환을 텍스트 버튼 → 아이콘 세그먼트 버튼으로, 선택을 `state.toml`에 저장·복원
- 경로바: 브레드크럼을 박스형으로
- 하단 상태바: 동기화 상태 · 현재 경로 · 항목 수
- 파일/폴더 아이콘을 이모지 → painter로 그린 벡터 아이콘 (폰트에 없는 글리프가 두부로 나오는 문제 원천 차단)

## 구현 메모
- 탭이 안 보이던 기존 버그 수정: 오른쪽 버튼 묶음 폭을 먼저 빼고 남은 폭에 탭을 그림(전엔 `right_to_left` 레이아웃이 폭을 전부 차지)
- 탭 카드(`tab_card`): 활성 탭은 패널 색 카드, 제목 앞 점 = 동기화 상태, 닫기 버튼은 활성/호버 시만
- 분할 모양 세그먼트 버튼 + `state.toml` `[ui] layout = "side"|"stacked"`
- 상태바: 동기화 상태(셸 OSC 7 cwd == 탐색기 폴더 → 동기화됨 / cd 대기·불일치 → 동기화 중 / 미수신 → 셸 경로 미확인) · `~` 축약 경로 · 항목 수
- 경로바: "탐색기" 제목 줄을 빼고 박스형 브레드크럼 + 트리/아이콘 전환을 한 줄로, 구분자 `/`
- 파일/폴더 벡터 아이콘은 DEV-022에서 선반영

## Test plan
- 자동: 탭 바에 탭이 폭을 갖고 그려지고 클릭 시 전환, 분할 모양 저장 왕복
- 사람 확인:
  - 탭 여러 개 열고 닫기(× 는 활성/호버 시만), 새 탭(+), 긴 폴더명 탭 말줄임
  - 분할 버튼으로 좌우/상하 전환, 재실행 시 유지
  - 상태바 동기화 표시: 탐색기에서 폴더 클릭·터미널에서 cd 했을 때 "동기화됨"으로 돌아오는지
  - 라이트/다크 양쪽에서 탭 카드·경로바·상태바 색
