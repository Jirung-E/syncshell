UI 시안(통합안) 중 테마·탐색기 외 나머지 크롬을 정돈한다.

시안: https://claude.ai/artifact/C5DJqUWwdJNrKDGxBCZsDz (통합안 아트보드)

## 범위
- 탭 바: 카드형 활성 탭 + 동기화 점, 새 탭/닫기 버튼을 그린 아이콘으로
- 분할 모양(좌우/상하) 전환을 텍스트 버튼 → 아이콘 세그먼트 버튼으로, 선택을 `state.toml`에 저장·복원
- 경로바: 브레드크럼을 박스형으로
- 하단 상태바: 동기화 상태 · 현재 경로 · 항목 수
- 파일/폴더 아이콘을 이모지 → painter로 그린 벡터 아이콘 (폰트에 없는 글리프가 두부로 나오는 문제 원천 차단)
