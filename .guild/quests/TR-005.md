**예광탄이 관통하는 지점.** 앞의 네 조각을 연결해 양방향 동기화를 성립시킨다.

## 범위
- `core`에 `SyncState` 하나 — 현재 경로의 단일 진리원. 양쪽이 이걸 구독
- **터미널 → 탐색기**: OSC 7으로 cwd 변경 감지 → 목록 갱신
- **탐색기 → 터미널**: 폴더 클릭 → 터미널에 `cd <경로>\n` 주입
- **에코 억제**: 주입한 `cd` 때문에 발생한 cwd 변경이 다시 탐색기를 건드리지 않도록.
  주입 시 "내가 기대하는 다음 경로"를 기록해두고, 그 값으로 도착한 변경은 무시하는
  정도면 예광탄엔 충분

## 생략 (의도적)
동기화 on/off 토글, 명령 입력 중 주입 시 입력 버퍼 보존, 셸별 인용 규칙,
탭/분할별 독립 동기화.

## 알려진 한계 (허용)
- 사용자가 명령을 치던 중에 폴더를 클릭하면 입력이 섞인다 → 예광탄에선 그냥 둔다
- 경로에 따옴표가 필요한 경우 깨질 수 있다 → 최소한의 인용만

## 완전판
[[DEV-006]] (양방향 동기화 완성), [[DEV-013]] (경로 추상화)

## Test plan
- 탐색기에서 폴더 클릭 → 터미널 프롬프트가 그 경로로 바뀐다
- 터미널에서 `cd ..` → 왼쪽 목록이 따라 올라간다
- 폴더를 연속으로 빠르게 클릭 → 최종 경로에 정확히 안착하고 무한 루프가 없다
- 공백·한글 포함 경로에서 양방향 모두 동작
