탐색기에서 선택한 파일의 내용을 미리 본다.

## 범위
- 텍스트: 앞부분만 읽어 표시 (크기 상한, 인코딩 판별 UTF-8/UTF-16/기타 → 실패 시 바이너리 취급)
- 이미지: png/jpg/gif/webp 등 축소 표시
- 그 밖(바이너리·큰 파일): 이름·크기·수정 시각 등 정보만
- 읽기는 UI 스레드 밖에서 (큰 파일·느린 드라이브에서 멈춤 없게)
- 배치(분할 안 세 번째 영역 / 탐색기 안쪽 등)와 켜고 끄기는 시안 제시 후 결정

## 결정 (2026-10-12)
시안 A(탐색기 안쪽)와 C(띄우는 창)를 함께 넣는다. A는 옵션으로 켜고 끄고(기본 꺼짐), C는 기본 동작.

## 구현
- core `preview::load` (배경 스레드에서 호출)
  - 텍스트: 앞 64 KB·1000줄까지. BOM(UTF-8/UTF-16LE/BE) → NUL 있으면 바이너리 → UTF-8 → CP949. 제어 문자 5% 초과면 바이너리. 읽기 상한에서 잘린 글자는 버림
  - 이미지: 확장자가 아니라 파일 앞부분으로 판별(png/jpeg/gif/webp/bmp/ico). 50 MB 초과는 정보만, 긴 변 1600px로 축소, 디코딩 메모리 상한
  - 그 밖: 크기·수정 시각만 + 사유(미리 볼 수 없는 형식/이미지가 큼/이미지 손상)
- C 훑어보기 창: 탐색기에서 파일 선택 + Space. Space·Esc·바깥 클릭·× 로 닫기, ↑↓(←→)로 이전·다음 파일(폴더 건너뜀, 목록도 따라 스크롤). 떠 있는 동안 키 입력은 터미널로 가지 않음
- A 미리보기 칸: 경로바 옆 눈 버튼으로 켜고 끔, `state.toml [ui] preview_pane`에 저장. 탐색기의 긴 쪽을 나눔(좌우 분할 → 목록 아래, 상하 분할 → 목록 오른쪽), 나누는 선을 끌어 비율 조절
- 탐색기를 클릭한 뒤 터미널에 글자를 치면 터미널 사용 중으로 전환 — 명령을 치다 누른 Space가 훑어보기를 열지 않게
- 원격 경로(DEV-030)는 이 읽기를 경로 추상화(DEV-013) 위로 옮길 때 같이 처리

## Test plan
- [ ] 파일 클릭 → Space: 창이 뜨고 내용 표시, ↑↓로 다음/이전 파일, Space·Esc·바깥 클릭으로 닫힘
- [ ] 창이 떠 있는 동안 타이핑이 터미널에 들어가지 않음
- [ ] 파일 클릭 후 터미널에 `ls -la` 입력 → 공백이 정상 입력되고 창이 안 뜸
- [ ] 텍스트(UTF-8 한글, CP949 메모장 파일, UTF-16 파일), 큰 로그(앞부분만 표시), 이미지(png/jpg/gif/webp), 바이너리(zip/exe) 각각 표시
- [ ] 눈 버튼: 좌우 분할에서 목록 아래, 상하 분할에서 목록 오른쪽에 칸. 나누는 선 끌기. 껐다 켜도(앱 재실행) 유지
- [ ] 다크/라이트 테마에서 창·칸·눈 버튼 모양
- [ ] Windows: Space가 터미널에 공백으로 새지 않음, 한글 IME 켠 상태 Space 동작
