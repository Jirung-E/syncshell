UI 시안(통합안, 2026-10-03 확정)의 색 체계를 적용하고 다크/라이트 모드를 사용자가 고를 수 있게 한다.

시안: https://claude.ai/artifact/C5DJqUWwdJNrKDGxBCZsDz (통합안 아트보드)

## 범위
- `Theme` (Dark/Light) 팔레트 정의 — 앱 크롬(배경/패널/테두리/글자/보조 글자/강조색/선택색)
  - Dark: bg #17181B, chrome #121316, panel #1E1F23, border #2A2C31, text #D7D9DE, muted #8B8F98, accent #6EA8FE, selection #2C3445
  - Light: bg #F4F4F2, chrome #ECECE9, panel #FFFFFF, border #DEDEDA, text #1F2023, muted #62666E, accent #2563D9, selection #DCE7FB
- egui `Visuals`를 팔레트에서 만들어 적용
- 터미널 기본 배경/전경 + ANSI 16색을 테마별로 (라이트 모드는 밝은 배경용 팔레트 — 노랑/흰색 계열이 흰 배경에서 안 보이는 문제)
- 선택은 앱 전역 하나, 종료 시 `state.toml`에 저장·복원 (앱이 쓰는 값이므로 config.toml이 아님 — architecture 규칙 3)
- 전환 UI: 탭 바 오른쪽에 라이트/다크 세그먼트 버튼

## 범위 밖
- 사용자 정의 테마/색 편집, OS 다크모드 자동 추종

## 구현 메모
- `syncshell-ui/src/theme.rs`: `ThemeMode`, `Palette`(DARK/LIGHT), `apply()` — egui `ThemePreference`를 고정해야 OS 테마에 끌려가지 않는다(egui 기본은 System 추종)
- `ansi_color.rs`: 기본 전경/배경·ANSI 16색을 `TermPalette`에서 받음
- `TerminalWidget::set_theme()` — `show()` 시그니처는 Windows 전용 테스트 때문에 유지
- `state.toml`에 `[ui] theme = "dark"|"light"` (예전 형식 파일도 그대로 읽힘 — 테스트 있음)
- `chrome.rs`: painter로 그리는 아이콘(해/달) + 세그먼트 버튼 — DEV-023에서 확장

## Test plan
- 자동: 대비 기준(본문·보조 글자·선택·터미널 4.5:1, 라이트 ANSI 3:1), 테마 전환 시 egui 패널 색 변경, 종료 상태에 테마 포함, `[ui]` 없는 예전 state.toml 로드
- 사람 확인:
  - 탭 바 오른쪽 해/달 버튼으로 전환하면 탐색기·터미널·메뉴(우클릭)·이름 바꾸기 대화상자까지 색이 바뀌는지
  - 라이트 모드에서 `ls -G`, git diff 등 색 출력이 흰 바탕에서 잘 읽히는지
  - 껐다 켜면 마지막 테마로 뜨는지
  - OS를 다크/라이트로 바꿔도 앱 테마가 따라 바뀌지 않는지(고정)
