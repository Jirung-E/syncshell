## 사용자 요청 확인 (구현 전, 요청만 기록) — 설계 질문 있음

"윈도우 기본 파일탐색기처럼 '탭'도 있어야함" — 실사용 중 요청.

**주의: 지금 이 퀘스트의 탭 설계와 사용자가 말한 탭이 같은 것인지 확인 필요.**
현재 범위는 "탭 하나 = (탐색기 경로 + 터미널 세션) 쌍"으로, 앱 전체의
작업 단위를 탭으로 나누는 모델이다. 사용자가 참조한 "Windows 기본 파일
탐색기의 탭"(Windows 11부터 추가된 기능)은 **탐색기 패널 자체의 다중
탭**(터미널과 무관하게 탐색기만 여러 폴더를 탭으로 열어두는 것)에 더
가까울 수 있다.

구현 착수 전에 확정할 것:
1. 앱 전체 탭(현재 설계, 탭마다 독립된 터미널+탐색기 쌍)으로 갈지
2. 탐색기 패널만 별도로 다중 탭을 갖게 할지(터미널과는 별개로)
3. 둘 다 필요한지(예: 앱 탭 안에 탐색기 서브탭)

사용자에게 재확인 후 착수할 것 — 지금은 요청만 기록.

## 설계 확정

위 댓글의 설계 질문에 대해 사용자 확인: **기존 설계(탭 = 탐색기 경로 +
터미널 세션 쌍)가 맞음.** 탐색기 패널만의 별도 다중 탭은 불필요.
착수 시 이 방향으로 진행.
