파일시스템 변경을 감시해 탐색기 뷰에 즉시 반영한다.

## 범위
- `notify` 크레이트(ReadDirectoryChangesW)로 현재 표시 중인 디렉터리 감시
- 생성/삭제/이름변경/수정 이벤트 → 리스트 증분 갱신 (전체 재조회 금지)
- 이벤트 폭주 시 디바운스 (예: 100ms)
- 디렉터리 이동 시 감시 대상 교체 및 이전 워처 해제

## Test plan
- 터미널에서 `New-Item` / `Remove-Item` 실행 시 탐색기에 즉시 반영
- 외부 프로그램(메모장 저장 등)의 변경도 반영
- 빌드 산출물 대량 생성(`cargo build`) 시 UI가 버티는지
