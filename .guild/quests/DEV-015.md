탐색기에서 파일 클릭 시 한 번만 눌러도 실행/열기가 되는 문제를 고친다.
일반 Windows 탐색기처럼 **더블클릭**해야 열리도록 바꾼다.

## 배경
TR-006 실사용 중 발견. 현재 `syncshell-ui/src/lib.rs`에서 파일 항목이
`ui.selectable_label(false, &label).clicked()`로 렌더링되는데, `clicked()`는
단일 클릭에도 true를 반환한다. 폴더는 단일 클릭 진입이 자연스럽지만(원래
TR-003 설계도 그랬음), **파일 실행은 실수로 한 번 눌러도 열려버려서 위험하다**
(실행 파일, 문서 등 의도치 않은 실행 가능).

## 범위
- 파일 항목: 더블클릭(`double_clicked()` 또는 클릭 시각 간격 추적)일 때만
  `open::that()` 호출
- 폴더 항목은 기존대로 단일 클릭 유지할지, 파일과 일관성 있게 폴더도
  더블클릭으로 통일할지 결정 필요 — 일반 탐색기는 폴더도 더블클릭이 기본이므로
  폴더도 더블클릭으로 통일하는 쪽이 자연스러워 보이지만, 예광탄 TR-003/TR-005
  설계는 단일 클릭 진입을 전제로 sync 로직이 짜여 있어 영향 범위 확인 필요.

## Test plan
- 파일을 한 번 클릭 → 아무 일도 안 일어남 (선택 표시 정도는 가능)
- 파일을 더블클릭 → 기본 프로그램으로 열림
- 폴더 클릭/더블클릭 동작이 사용자가 기대하는 대로인지 확인
