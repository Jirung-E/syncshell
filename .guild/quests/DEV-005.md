자체 파일 탐색기 UI를 구현한다.

## 범위
- 좌측 트리(디렉터리 계층) + 우측 리스트(현재 폴더 내용) 레이아웃
- 파일 아이콘, 크기, 수정일 표시
- 더블클릭으로 폴더 진입 / 파일 열기(연결 프로그램)
- 경로 브레드크럼(조상 폴더 클릭 시 바로 이동)
- 대용량 디렉터리(수천 개 파일) 가상 스크롤

## 범위 제외 (2026-08-06 결정)
- 경로 직접 입력(텍스트로 타이핑해서 이동)은 필요 없음 — 터미널에서 `cd`를 치면 어차피
  탐색기와 동기화되므로 커맨드라인이 그 역할을 대신함.

## 메모
- 디렉터리 읽기는 `core`에서 백그라운드 스레드로 — UI 블로킹 금지
- 아이콘은 셸 아이콘 추출(SHGetFileInfo)보다 확장자 기반 정적 아이콘으로 시작

## Test plan
- `C:\Windows\System32` 같은 대용량 폴더에서 스크롤이 끊기지 않는지
- 한글/특수문자 파일명 정상 표시
- 접근 권한 없는 폴더 진입 시 크래시 없이 오류 표시
- 트리에서 폴더 클릭 시 우측 리스트 및 탐색기 현재 경로가 정확히 따라가는지
- 브레드크럼의 조상 폴더 클릭 시 해당 경로로 정확히 이동하는지
