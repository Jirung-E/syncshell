DEV-006의 원래 스펙("동기화 일시 해제 토글 (탐색기만 따로 보고 싶을 때)")에
있던 대로 구현했었음 — 탐색기 헤더에 "터미널과 동기화" 체크박스를 추가하고,
끄면 양방향 자동 추종이 멈추게 했다.

## 취소 사유

- **버그**: 껐다가 다시 켜도 즉시 재동기화가 안 됨 — 다음 클릭/cd가 있을
  때까지 두 패널이 어긋난 채로 남는다(단순히 "앞으로의 이벤트만 다시 지켜보기
  시작"할 뿐, 지금 당장 맞춰주는 동작이 없었음).
- **더 근본적으로**: 사용자가 이 기능 자체를 기대하지 않았음("난 항상
  동기화되는걸 생각했었는데"). 애초에 이 프로젝트의 핵심 가치가 "탐색기 ↔
  터미널 실시간 양방향 동기화"인데, 그걸 끌 수 있게 하는 토글이 오히려
  혼란을 준다는 피드백.
- **대안이 이미 있음**: DEV-009에서 다중 탭을 붙였으므로, 탐색기를 터미널과
  별개로 따로 둘러보고 싶으면 그냥 새 탭을 열면 된다(탭마다 독립된 탐색기+
  터미널+동기화 상태를 가짐) — 토글이라는 별도 개념이 굳이 필요 없어짐.

## 되돌린 내용
- `FilePanelState.sync_enabled` 필드, 헤더 체크박스 UI 제거
- `lib.rs`의 모든 `sync_enabled` 게이팅 제거 — 이제 항상 양방향 동기화
- `config.toml`의 `sync_enabled_default` 설정도 같이 제거(의미가 없어짐)
- 관련 유닛테스트 2개 제거, `cargo test --workspace` 65개 전부 통과 재확인
