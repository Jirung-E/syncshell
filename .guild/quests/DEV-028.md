자주 가는 폴더를 즐겨찾기로 등록하고 한 번에 이동한다.

## 범위
- 탐색기에 즐겨찾기 줄(또는 목록) 표시, 클릭 시 해당 경로로 이동 → 기존 양방향 동기화로 터미널도 이동
- 추가/삭제: 현재 폴더·탐색기 항목 우클릭에서 "즐겨찾기에 추가", 즐겨찾기 항목 우클릭에서 제거
- 저장: 사람이 직접 고칠 수 있도록 `~/.syncshell/config.toml`에 둔다 (앱이 쓸 때 주석·포맷 보존 필요 — toml_edit 등 검토)
- 존재하지 않는 경로는 흐리게 표시, 클릭 시 오류 대신 안내

## 메모
- 원격 연결(DEV-013 경로 추상화) 이후 원격 경로도 담을 수 있게 저장 형식을 잡아 둘 것
