자주 가는 폴더를 즐겨찾기로 등록하고 한 번에 이동한다.

## 범위
- 탐색기에 즐겨찾기 줄(또는 목록) 표시, 클릭 시 해당 경로로 이동 → 기존 양방향 동기화로 터미널도 이동
- 추가/삭제: 현재 폴더·탐색기 항목 우클릭에서 "즐겨찾기에 추가", 즐겨찾기 항목 우클릭에서 제거
- 저장: 사람이 직접 고칠 수 있도록 `~/.syncshell/config.toml`에 둔다 (앱이 쓸 때 주석·포맷 보존 필요 — toml_edit 등 검토)
- 존재하지 않는 경로는 흐리게 표시, 클릭 시 오류 대신 안내

## 메모
- 원격 연결(DEV-013 경로 추상화) 이후 원격 경로도 담을 수 있게 저장 형식을 잡아 둘 것

## 구현
- 경로바 오른쪽 별 버튼: 현재 폴더를 즐겨찾기에 추가(빈 별) / 제거(채운 별, 강조색).
- 즐겨찾기가 하나라도 있으면 경로바 아래에 즐겨찾기 줄(폴더 이름 칸). 누르면 그 폴더로 이동 → 터미널도 따라감. 지금 폴더인 칸은 강조, 넘치면 가로 스크롤.
- 없어진 폴더는 흐리게 표시, 누르면 이동하지 않고 "폴더가 없습니다" 안내. 마우스를 올리면 전체 경로.
- 우클릭: 폴더 항목 "즐겨찾기에 추가/제거", 경로바(현재 폴더) 메뉴에도 같은 항목, 즐겨찾기 칸은 "경로 복사"/"즐겨찾기에서 제거".
- 저장: `~/.syncshell/config.toml`의 `favorites = [ ... ]`(한 줄에 하나). 앱은 이 항목만 고쳐 쓰고 다른 설정·주석은 보존(toml_edit). 파일이 깨져 있으면 덮어쓰지 않고 오류 안내. 사람이 직접 고쳐도 되며 다음 실행부터 반영.
- 목록은 탭과 무관한 앱 전역.

## Test plan
- 별 버튼으로 현재 폴더 추가 → 별이 채워지고 경로바 아래 즐겨찾기 줄에 나타남, 다시 누르면 빠짐
- 즐겨찾기 칸 클릭 → 탐색기와 터미널이 그 폴더로 이동
- 폴더 항목 우클릭 "즐겨찾기에 추가", 즐겨찾기 칸 우클릭 "즐겨찾기에서 제거"
- 앱을 껐다 켜도 즐겨찾기 유지, `config.toml`에 주석을 달아 둬도 추가·제거 후 주석 그대로
- 즐겨찾기한 폴더를 지운 뒤 → 흐리게 보이고 눌러도 이동 안 함(안내만)
- 다크/라이트 테마에서 별·칸이 잘 보이는지, 즐겨찾기가 많을 때 가로 스크롤
- (단위 테스트: 저장 시 주석 보존·깨진 파일 보호, 별 토글, 칸 이동, 없는 폴더 안내. 화면 모양은 자동 확인 못 함 — 사람 확인 필요)
