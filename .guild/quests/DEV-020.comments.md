## 구현
- `SyncShellApp.panel_layout: PanelLayout`(Side/Stacked, 세션 전체 하나 — 탭별 아님). 탭 바 오른쪽 끝에 토글 버튼("레이아웃: 상하로"/"레이아웃: 좌우로" — 지금 상태가 아니라 눌렀을 때 될 상태를 라벨로 보여줌, 안 그러면 눌러도 안 바뀐 것처럼 헷갈림).
- `ui()`에서 `egui::Panel::left`/`egui::Panel::top`을 `panel_layout`에 따라 갈라 씀 — 둘 다 같은 빌더 API(`resizable`/`default_size`)라 나머지 코드는 공통. 좌우 모드는 폭(기본 320px), 상하 모드는 높이(기본 220px) 드래그 조절.

## 테스트
`panel_layout_toggle_switches_between_side_and_stacked` — 토글이 좌우↔상하를 왕복하는지, 라벨이 "될 상태"를 안내하는지.

`cargo test --workspace` 80개 통과. 앱 실행 후 스크린샷으로 토글 버튼이 탭 바에 뜨는 것까지 확인(사람 확인 대기: 실제로 버튼을 눌러서 상하 배치가 자연스러운지, 드래그로 높이 조절이 잘 되는지는 자동 클릭 시뮬레이션으로 못 잡아서 — 이 머신에 손 마우스 클릭을 흉내낼 손쉬운 방법이 없었음, cliclick/PyObjC Quartz 둘 다 없음).
