터미널 글자가 창 가장자리·탐색기 경계에 바로 붙어 있어 보기 불편하다(2026-10-04 Windows 사용자 피드백: "콘솔부분이, 창 경계와 간격이 아예 없어서 보기 불편함"). UI 시안에도 터미널 안쪽 여백이 있었다(위아래 14, 좌우 18).

## 범위
- 터미널 영역에 안쪽 여백 — 여백도 터미널 바탕색(테마별)으로 칠해서 터미널이 한 덩어리로 보이게
- 마우스 선택·스크롤·파일 드롭 영역은 기존대로 동작

## 구현
- `TERMINAL_PADDING` (왼 12, 오 8, 위 8, 아래 6) — 터미널 칸 수를 너무 잃지 않게 시안보다 조금 줄임
- CentralPanel 프레임을 터미널 바탕색(테마별)으로 칠하고 inner_margin

## Test plan
- macOS 다크 모드 화면으로 여백 확인함
- 사람 확인(Windows): 여백이 보기 좋은지, 라이트 모드에서 여백이 터미널과 같은 색인지, 터미널 텍스트 드래그 선택·마우스 휠 스크롤·파일 드롭이 그대로 되는지
