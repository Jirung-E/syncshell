## 구현 현황 (예광탄 이후, TR-006 회고 반영)

**핵심 동기화는 완성 수준으로 구현됨.** `crates/syncshell-core/src/sync.rs`의
`SyncState` — 양방향 동기화, 상대경로 cd 주입(직계 자식/부모일 때), 에코
억제, 사용자 타이핑 중 주입 지연(큐잉) 전부 실제 PowerShell로 검증됨.

**실사용에서 드러나 고친 버그들**(원래 이 퀘스트가 다룰 만한 것들이었는데
TR-005/TR-006에서 먼저 발견·수정됨):
- `session.cwd` 매 프레임 재통지로 인한 레이스(클릭 시 탐색기가 옛 폴더로
  튀는 버그) → `take_cwd_change()` 도입
- 사용자가 터미널에 타이핑 중(제출 전)일 때 탐색기 클릭의 cd 주입이 끼어들어
  명령이 깨지는 문제 → `pending_user_input` 추적 + 큐잉
- 절대경로 대신 상대경로("cd .."/폴더명) 주입으로 변경
