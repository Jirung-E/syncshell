파일 조작 기능과 드래그 앤 드롭을 구현한다. **플랫폼 API를 직접 부르지 말 것.**

## 범위
- 생성 / 삭제(휴지통) / 이름 변경 / 복사 / 잘라내기 / 붙여넣기
- 컨텍스트 메뉴
- 앱 내부 드래그 앤 드롭
- 외부 드롭 수신 (OS 파일 관리자에서 끌어다 놓기) — winit의 `DroppedFile` 이벤트
- 파일을 터미널에 드롭 → 경로 텍스트 삽입 (플랫폼별 인용 규칙 주의)
- 진행률 표시 및 취소 (대용량 복사)

## 크로스플랫폼 방침
- **휴지통**: `SHFileOperation`/`IFileOperation` 직접 호출 금지 → **`trash` 크레이트**
  (Windows 휴지통, macOS 휴지통, Linux XDG trash를 모두 처리)
- **파일 열기**: `ShellExecute` 직접 호출 금지 → **`open` 크레이트**
  (Windows `start`, macOS `open`, Linux `xdg-open`)
- 복사/이동은 `std::fs` 기반으로 직접 구현 (진행률·취소가 필요하므로 청크 단위 복사)
- 영구 삭제는 명시적 선택으로만 (Shift+Delete 등)

## Test plan
- 각 조작 후 뷰와 실제 파일시스템 상태 일치
- 대용량 파일 복사 중 취소 시 부분 파일 정리
- 권한 오류 / 사용 중 파일에서 크래시 없이 명확한 오류 메시지
- 충돌 시 덮어쓰기/이름변경/건너뛰기 선택 동작
