터미널 위젯의 텍스트 선택·복사·붙여넣기와 IME 조합 입력을 구현한다.

## 범위
- 드래그 선택, 더블클릭(단어)·트리플클릭(줄) 선택, 블록 선택
- 복사/붙여넣기 키바인딩 (Ctrl+Shift+C/V 등, 플랫폼별 관례 반영)
- 붙여넣기 시 bracketed paste mode 지원
- 마우스 리포팅 (vim 등 TUI 앱이 마우스를 받는 모드)
- **IME 조합 입력(preedit) 처리**

## IME — 이 퀘스트의 실제 난점
egui의 기본 `TextEdit`은 한글 조합이 되는 편이라 파일명 변경·검색창은 문제없다.
문제는 **커스텀 셀 그리드 위젯**이다. 여기서는 winit의 IME 이벤트
(preedit / commit)를 직접 받아 조합 중인 글자를 커서 위치에 그려야 한다.

실제 시나리오: 터미널에서 `git commit` → vim이 뜨고 → 한글 커밋 메시지 입력.
이게 되지 않으면 한국어 사용자에게 도구가 성립하지 않는다.

- 조합 중 텍스트는 PTY로 보내지 않고 화면에만 그린다. 확정(commit) 시점에만 전송
- 조합 문자열의 셀 폭 계산 필요 (DEV-011의 폭 2 처리와 연동)
- IME 후보창 위치를 커서 좌표로 알려줘야 함 (winit의 IME cursor area 설정)

## Test plan
- 터미널 안 vim에서 한글 입력 → 조합 과정이 커서 위치에 표시되고 확정 시 정상 입력
- 조합 중 ESC / 백스페이스 동작
- IME 후보창이 커서를 따라오는지
- 한글 포함 영역 드래그 선택 → 복사 → 붙여넣기 라운드트립에서 깨짐 없음
- 일본어·중국어 IME에서도 동일 동작 (가능하면)
