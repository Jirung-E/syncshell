현재 경로를 클립보드로 바로 복사할 수 있게 한다.

## 범위
- 상태바 경로 클릭 → 현재 탭 경로 복사 (복사됨 표시)
- 단축키 (예: Ctrl/Cmd+Shift+C는 터미널 복사와 겹치므로 별도 키 검토)
- 탐색기 항목 우클릭 메뉴 "경로 복사" (항목의 전체 경로)
- 복사 형식은 OS 기본 표기 (Windows `C:\...`, 그 외 `/...`)

## 구현
- 탐색기 우클릭 "경로 복사"(항목)·"현재 경로 복사"(빈 곳)는 DEV-008에서 이미 있었음 — 그대로.
- 상태바 경로 클릭 → 현재 탭 전체 경로 복사, 옆에 "복사됨" 1.5초 표시. 마우스를 올리면 전체 경로와 단축키 안내.
- 단축키: macOS Cmd+Option+C, Windows/Linux Shift+Alt+C(VS Code "경로 복사"와 같은 키). 터미널에 글자가 새지 않게 먼저 꺼내 지운다. 그냥 Cmd/Ctrl+C(터미널 복사)는 그대로.

## Test plan
- 상태바 경로 클릭 → 클립보드에 전체 경로(`~` 아닌 실제 경로), "복사됨" 잠깐 표시
- macOS: Cmd+Option+C / Windows: Shift+Alt+C → 현재 경로 복사, 터미널에 글자가 입력되지 않음
- 터미널에서 텍스트 선택 후 Cmd+C(macOS)/Ctrl+Shift+C 등 기존 복사는 그대로 동작
- 탐색기 우클릭 "경로 복사"/"현재 경로 복사" 그대로 동작
- (단위 테스트로 단축키 판정 확인. 실제 키 입력은 Mac 자동화가 시스템 단축키로 새어 확인 못 함 — 사람 확인 필요)
