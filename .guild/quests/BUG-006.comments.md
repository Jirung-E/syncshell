진단 표시 추가(아직 원인 미확정, 수정 아님). Windows에서 `$env:SYNCSHELL_PROFILE=1; cargo run --release`로 실행 → 키를 꾹 누른 채 몇 초 → 상태바 오른쪽(강조색)과 콘솔의 `[profile]` 줄을 보면 된다.

읽는 법:
- UI 평균/최대가 수 ms 이하인데 간격 최대가 길다(수십~수백 ms) → 렌더러 present/vsync 쪽
- PTY 쓰기 최대가 길다 → UI 스레드 PTY 쓰기 막힘(쓰기를 별도 스레드로 옮기면 해결)
- UI 최대 자체가 길다 + 파싱 시간이 크다 → 출력 파싱/그리기 비용
- 이벤트 최대/프레임이 크게 쌓인다 → 프레임이 이벤트를 못 따라감

macOS release 기준(프레임 단위 측정, headless): 터미널 그리기 0.2ms, 탐색기 0.04ms, 타이핑 중 1~2ms.
