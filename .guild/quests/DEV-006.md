탐색기와 터미널의 실시간 양방향 디렉터리 동기화를 구현한다. **프로젝트의 핵심 기능.**

## 범위
- **터미널 → 탐색기**: cwd 추적 결과가 바뀌면 탐색기 뷰를 해당 경로로 이동
- **탐색기 → 터미널**: 폴더 이동 시 터미널에 `cd` 주입
- 무한 루프 방지: 주입한 `cd`로 인한 cwd 변경이 다시 탐색기 이동을 유발하지 않도록 에코 억제
- 사용자가 터미널에 명령 입력 중일 때 `cd` 주입 처리 (입력 버퍼 보존 또는 지연)
- 동기화 일시 해제 토글 (탐색기만 따로 보고 싶을 때)

## 메모
- 동기화 상태를 단일 소스(`core`의 SyncState)로 두고 양쪽이 구독하는 구조
- 주입한 명령에 시퀀스 번호를 붙여 자기 자신이 유발한 변경인지 판별

## Test plan
- 탐색기에서 폴더 여러 번 빠르게 클릭 → 터미널이 최종 경로에 정확히 안착
- 터미널에서 `cd ..` 반복 → 탐색기가 따라옴
- 명령 입력 중(엔터 전) 탐색기 이동 시 입력한 내용이 날아가지 않는지
- 동기화 토글 off 상태에서 양쪽이 독립 동작
